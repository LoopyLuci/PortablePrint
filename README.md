# Print Master Replica

A desktop application to replace the Print Master mobile app, enabling Bluetooth connection to label makers (e.g., Phomemo D30, P12, M110 series) for creating and printing labels for home organization, kitchen storage, document filing, health reminders, and holiday messages.

## Features

- **Lite Mode**: Quick label creation by typing text only.
- **Creative Mode**: Insert images, icons, and formatted text for versatile label designs.
- **Bluetooth Connectivity**: Pair with compatible Bluetooth label printers.
- **Label Design**: Support for various label sizes and styles.
- **Text Editing**: Fonts, sizes, alignment, and styling.
- **Graphics Support**: Import images and icons.
- **Template Management**: Save and reuse label designs.
- **Print Queue**: Manage multiple label prints.
- **Cross-Platform**: Built for Windows (with potential for macOS/Linux).

## Supported Printers

- Phomemo D30, P12, P12 PRO
- M960, M950, M110, M120, M200, M220, M221
- D50, Q30, Q30S, LM1600, LT12, E975, P3200
- And other Bluetooth label makers that work with the Print Master app.

## Getting Started

1. Clone this repository.
2. Install dependencies (see `requirements.txt` or `package.json`).
3. Enable Bluetooth on your computer and pair with your label maker.
4. Run the application and start designing labels.

## Development

This project aims to replicate the core functionality of the Print Master app (com.project.aimotech.printmaster) while providing a desktop-native experience.
